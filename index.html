Akses Database Ditolak!

Firebase memblokir Anda untuk menyimpan/membaca data. Ini sering terjadi karena Security Rules belum diatur dengan benar.

1 Buka Firebase Console > Authentication > tab Sign-in method > Aktifkan Anonymous.

2
Buka Firestore Database > tab Rules. Ganti semua teks menjadi: rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }
